# 🚀 Rishav Raj - Personal Portfolio

An elegant, modern, and fully responsive personal portfolio web application built with **React 18**, **Vite**, **Framer Motion**, and **Bootstrap 5**.

## ✨ Features

- 🌓 **Dark & Light Mode Support**: Seamless theme switcher with persistent user preference using `localStorage`.
- ⚡ **Blazing Fast**: Powered by **Vite** for rapid hot-module reloading and optimized production bundles.
- 📱 **Fully Responsive**: Mobile-first design that adapts fluidly across all screen sizes.
- 🎭 **Dynamic Micro-Animations**: Smooth entry animations and micro-interactions powered by **Framer Motion**.
- 🎨 **Modern Typography & Icons**: Integrated Google Fonts (*Outfit* & *Plus Jakarta Sans*) and **FontAwesome 6** icons.
- 🧩 **Clean Component Architecture**: Modular and easily maintainable React components.

---

## 🛠️ Tech Stack

- **Frontend Core**: React 18, HTML5, CSS3, JavaScript (ES6+)
- **Build Tool**: Vite
- **Animations**: Framer Motion
- **UI Framework & Styling**: Bootstrap 5 + Custom Modern CSS Design System
- **Fonts & Icons**: Google Fonts, FontAwesome 6

## 🚀 Getting Started

Follow these steps to run the project locally on your machine:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed (v16+ recommended).

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Rishav7739/webPortfolio4.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd webPortfolio4
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the local development server:**
   ```bash
   npm run dev
   ```

5. **Open in browser:**
   Open [http://localhost:5173](http://localhost:5173) in your browser to view the portfolio.
